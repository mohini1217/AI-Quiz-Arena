# 🎯 AI Quiz Arena

### Test Your Knowledge. Challenge Yourself. Learn Smarter!

AI Quiz Arena is an interactive quiz-based learning platform designed to make learning more engaging and enjoyable. Users can create an account, attempt quizzes, receive real-time scores, and track their quiz performance.

## ✨ Features

* **User Authentication:** Register and log in using email and password.
* **Interactive Quizzes:** Attempt quizzes through an easy-to-use interface.
* **Real-Time Scoring:** Get your score after completing a quiz.
* **Result Tracking:** Save quiz results and view previous attempts.
* **Dashboard:** Access your quiz activity and performance history.
* **Database Integration:** Store user information and quiz results securely.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/mohini1217/AI-Quiz-Arena.git
```

### 2. Open the Project Folder

```bash
cd AI-Quiz-Arena
```

### 3. Install Frontend Dependencies

```bash
npm install
```

### 4. Start the Frontend

```bash
npm run dev
```

### 5. Backend Setup

Open the backend folder in a separate terminal:

```bash
cd backend
npm install
```

Configure the required environment variables in a `.env` file before starting the backend.
